AgriPak Farms-Low-Yield Risk Prediction

Project Description

This Machine Learning project aims to predict agricultural fields that are at risk of low crop yield before harvest.it uses data preprocessing ,data cleaning,and logistic regressions to identify potential low-yield risks.

Objective

To develop a reliable Machine Learning model that helps identify low-yield risk and support better agricultural decisions.

Technologies Used

*Python
*Pandas
*Numpy
*Sciki-Learn
*Machine Learning
*GitHub

Project Tasks

1.create a GitHub repository 
2.Load and clean the crop dataset
3.Perform an 80/20 train-test split
4.Train a Logistic Repressions model
5.Evaluate model performance 
6.Perform a data leakage check
